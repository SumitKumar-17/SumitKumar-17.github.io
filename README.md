# SumitKumar-17.github.io

Source code for my [personal website](https://sumitkumar-17.github.io/), hosted
on GitHub Pages and [Vercel](sumitkumar17.vercel.app)

This website is powered by [SvelteKit](https://kit.svelte.dev/) and
[Tailwind CSS](https://tailwindcss.com/). To develop, run:

```sh-session
$ npm install
$ npm run dev
```
