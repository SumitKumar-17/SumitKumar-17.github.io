Built an AI-driven system to monitor employee well-being using behavioral signals, automated insights, and LLM pipelines. The system processed data from 1,000+ users through a multi-stage pipeline built with FastAPI, scheduled CRON jobs, and performance metrics.

It flagged high-risk users with 42% improved accuracy using EMA-weighted scores and ensemble models, and orchestrated an LLM-powered chatbot and summaries via LangChain pipelines, enabling context-aware insights into how people on the platform were actually doing.
