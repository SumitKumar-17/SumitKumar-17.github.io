I made this custom small Database project for the Database Management Laboratory Final Project.
Was bored to implement the Full Stack Ideas present in the list of Ideas. So i decided to go with my own idea , of making a Database (sounded cool :)).

[KeystoneDB](https://keystonedb.sumitk.me) isthe final project developed.
A custom lexer and SQL parser for the Query language and then query engine which parses those query and then decides how to take the data from the RocksDB. used kind of LSm format to store the Data
